Commands to generate an embeddable header for ESP32-S3 (CIFAR10 Mobilenet v2 int8), compatible with `src/main.cpp`:

# 1) Generate a C header from the int8-quantized TFLite model
# 2) Keep generated symbols as-is (main.cpp now expects model_simple_int8_tflite)
# 3) Add const + PROGMEM to keep the model in Flash memory (avoid DRAM overflow)
# 4) (Optional) Verify that final symbols are correct


cd src

xxd -i model_simple_int8.tflite > model_simple_int8.h


sed -i '1i #include <pgmspace.h>\n' model_simple_int8.h
sed -i 's/^unsigned char /const unsigned char /' model_simple_int8.h
sed -i 's/^unsigned int /const unsigned int /' model_simple_int8.h
sed -i 's/\[\] =/[] PROGMEM =/' model_simple_int8.h


grep -n "model_simple_int8_tflite" model_simple_int8.h
grep -n "^const unsigned char model_simple_int8_tflite\\[\\] PROGMEM = {" model_simple_int8.h
